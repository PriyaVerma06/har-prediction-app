One window. One activity.

This model reads a single window of 128 consecutive sensor readings, each with 9 features (body acceleration + gyroscope, mean & std, X/Y/Z), and classifies the whole window as one activity. File must be exactly 128 rows × 9 columns with no header row or extra id column. Supports channel labels, signal inspection, and full confidence scoring.

    SYSTEM OVERVIEW

    What is Human Activity Recognition (HAR)?

    Human Activity Recognition (HAR) transforms raw inertial sensor streams from modern smartphones and wearables into actionable physical activity classifications. By processing high-frequency 3D acceleration and angular velocity signals through deep temporal networks, HAR automatically identifies everyday movements without intrusive vision hardware.

    Dataset & Sensor Specifications

    This model was trained on the benchmark UCI Machine Learning Repository HAR Dataset captured via waist-mounted smartphone inertial measurement units (IMUs).

    Sampling Frequency 50 Hz (50 samples per second)
    Window Duration 128 consecutive timesteps (~2.56 seconds)
    Sensor Channels (9) Body Acc (X, Y, Z), Body Gyro (X, Y, Z), Total Acc (X, Y, Z)
    Target Activities (6) Walking, Walking Upstairs, Walking Downstairs, Sitting, Standing, Laying

    ARCHITECTURE DEEP DIVE

    Recurrent Neural Network (GRU) Model

    Time-series motion sensors require deep learning models capable of capturing temporal dependencies across consecutive timesteps. Gated Recurrent Units (GRU) utilize gating mechanisms (Reset Gate & Update Gate) to process temporal motion dynamics while mitigating vanishing gradients.
